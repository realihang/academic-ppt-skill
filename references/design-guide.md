# 母版与参考页索引

默认16:9画布：13⅓×7½英寸，12192000×6858000 EMU。可选4:3画布：10×7½英寸，9144000×6858000 EMU。分别使用assets/reference.pptx和assets/reference-4x3.pptx。保留学术风格3(169)的一个原生母版和五种版式。中文微软雅黑，英文及数字Arial。

封面主标题通常44—48磅，副标题30—34磅，汇报人28磅，论文作者和版本22磅。主标题随题名长度调整，保证视觉上舒展。正文页标题36磅，正文、表格与总结28磅。

| 原生版式 | 总结结构 | 主要占位符 |
| --- | --- | --- |
| 目录 | 按材料生成章节并高亮当前项 | 标题idx=10 |
| 版式1 | 无总结 | 标题idx=10，正文idx=12 |
| 版式2 | 一行总结 | 标题idx=10，正文idx=12，总结idx=11 |
| 版式3 | 蓝底白字两行总结 | 标题idx=10，正文idx=12，总结idx=11 |
| 自由版式 | 按内容排布 | 保留画布与字体规范 |

标题通常为body类型占位符，结合位置识别，明确设置文字颜色。表格每一单元格水平、垂直居中，多行段落也逐段居中。

## 原生列表与讲解动画

并列要点使用原生实心正方形“■”，默认主蓝，方块视觉高度约为正文可见高度的三分之二。Arial符号配28磅正文时，可从140%的符号字号起步，以实际显示比例调整。保持适度间距，悬挂宽度容纳方块与间隙，续行与正文起点对齐。一个要点配一个符号，其解释在同一段内换行，避免用空格模拟列表。

页面直接切换，正文默认静态。仅当分步讲解确有需要时，才把对应对象命名为 `reveal-1-说明` 与 `reveal-1-所属底纹`。原图与图例完整显示，按讲解需要一次点击显示一组解释。

```text
python scripts/apply_presenter_effects.py --source <起稿.pptx> --output <带动效.pptx> --duration 350
```

静态页无需调用动画脚本；脚本只为明确标记的讲解对象设置淡入，并移除页面切换效果。对已有时序统一时明确使用 `--replace-existing`。核对对象目标、唯一编号、点击提示与目录跳转。编辑视图和静态预览显示全页，点击效果在PowerPoint放映模式查看。

## 页面比例适配

默认16:9；用户要求4:3时保留正文36/28磅规范和图片原始比例，重新分配列宽、图表区域和留白。长标签可合理换行，密集多面板原图可按面板重排，并保留坐标、图例、参数及阅读顺序；备注同步更新。4:3示例预览为assets/previews/template-4x3.png。
