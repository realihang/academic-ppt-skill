# 内容组织、配色与元素

## 目录与覆盖

先阅读本次材料，归纳其关键问题、方法、证据和边界，再确定章节。题名、数量和页序随材料变化，目录与备注同步更新。科研汇报不必套用固定数量的背景、方法、结果、讨论条目。

用简短对应表检查材料要点是否出现在正文或备注：核心方法与使用条件、数据与基线、指标与单位、主要结果、验证或消融、结论范围。理解研究所必需的信息在正文体现，深入推理放备注。正文保留一份清楚的事实，总结解释其含义，避免机械复述图表数字。

## 表格与并列要点

所有表格单元格水平居中、垂直居中，包括第一列、表头及多段落。保持一致的左右内边距，按文字分配列宽、行高，英文名称与单位完整显示。

并列条目采用原生无序列表，默认使用较大的主蓝实心正方形“■”，按实际可见比例放大符号，使方块高度约为文字高度的三分之二。悬挂缩进应能容纳方块及其与文字的间隙，避免重叠。一条要点只有一个符号，标题与解释属于同一条，续行与正文起点对齐。使用适度项目间距，避免把从属说明误列成同级。流程或因果关系仍按其实际结构表达。

模板文字行距统一为1.2倍，列表和表格内文字同样设置。字号按内容层级设置：一级24磅、二级22磅、三级20磅。正文、表格和原生图表不要求所有文字都为24磅；图例、图注与辅助标签可适当减小。字体层级及总结选择以 design-guide.md 为准，缩小字号须服务于信息层次，不能用来塞入过多内容。

## 八色色板

| 颜色 | 色值 | 主要用途 |
| --- | --- | --- |
| 主蓝 | #084B99 | 标题、标签、节点与箭头；蓝底使用白字 |
| 浅蓝 | #ECF2FE | 分组底色、轻量图框与交替表格行 |
| 浅黄 | #FDFFEB | 条件、定义或局部提示的底色 |
| 灰色 | #7F7F7F | 部分图形边框、图框与辅助轮廓 |
| 黑色 | #000000 | 浅底正文与普通解释 |
| 红色 | #C00000 | 少量关键差异或短语 |
| 黄色 | #FFFF00 | 少量局部背景标记配黑字，或在深蓝底上强调短语 |
| 白色 | #FFFFFF | 画布、留白、主蓝底文字 |

灰色用于需要中性轮廓的图形边框，按信息层次选取。浅蓝色继续用于底色，需要清楚边界的图框、容器及表格轮廓使用灰色，避免以浅蓝细线勾边造成模糊；主蓝仍用于标题、节点与关系箭头。正文沿用明确的黑字或蓝底白字，不因新增边框色降低文字对比。边框需显式设置灰色与完整不透明度，检查主题继承、透明度和颜色变换后的实际效果，保留实线或虚线的结构含义。母版画布右侧保留八色色卡，顺序为主蓝、浅蓝、浅黄、灰、黑、红、黄、白；两种比例均保持色块等大与间距协调。

## 明确的文字与底色

| 背景 | 默认文字 | 局部强调 |
| --- | --- | --- |
| 白色 `FFFFFF` | 黑色 `000000` | 主蓝小标题、少量红色数字 |
| 浅蓝 `ECF2FE` | 黑色 `000000` | 主蓝短标题 |
| 浅黄 `FDFFEB` | 黑色 `000000` | 少量红色关键词 |
| 主蓝 `084B99` | 白色 `FFFFFF` | 少量黄色短语、字重与间距 |
| 黄色 `FFFF00` | 黑色 `000000` | 少数短词 |

正文文字与实际背景尽量达到4.5:1以上对比。文字与底纹分别显式设置颜色，检查表头、总结条、分组和动画后的叠放。原图保留源色，不因装饰调整科学信息。

## 小标题与尺寸

小标题可以使用主蓝、加粗、一根窄竖条或直角浅色块建立层次。新建矩形默认直角；确需圆角时控制为轻微小倒角，避免胶囊形。圆形节点、项目符号和原始科学图中的形状按其语义保留。

以1280×720画布为例，24磅一级小标题对应的直角标题条高度可从48—60像素起步，留足文字内边距；竖条宽度约4—6像素，与标题文字留出清楚间距。最终看实际显示比例调整，不让修饰压过正文。

原图配少量解释、表格配一句判断已经清楚时保持简洁。分隔线只有在明确表达边界且比留白更清楚时才使用。并列内容优先依靠列表、对齐与段落间距分组。

## 用户参考与示意图

元素与排版统一查看 `assets/element-reference.pptx`，按 `references/element-catalog.md` 检索；当前审阅稿待用户优化，最终以用户回传版本为准。案例中可复用的经验是章节回访、信息邻近、对齐与清楚的证据阅读顺序；结合当前字体、直角样式和色板，按需取用。格式参考使用通用文字与空图框。材料正文、原始图表、备注及包含正文的预览只用于本次汇报，不打包分享。

先选合适原图，缺少示意时用PPT原生形状简单绘制。只有原图与原生形状确实难以表达时才使用AI示意图，统一白底、色调、线宽、字体与留白。真实结果和数值依据材料。

页面直接切换，正文默认静态。只有方法步骤、公式推导、流程或图中关系确需分步解释时才设置动画；为每个动画写明讲解目的。原图完整可见，必要解释与底纹同组淡入。普通总结、目录和装饰不需要额外点击。备注包含完整中文讲稿、出处、证据边界与实际点击提示。

## 原生箭头与部件

K类集中提供边界容器、标注框、标签、括号、节点及箭头。K08为渐变短箭头，K09为收束上升箭头，K10为渐变弯回箭头，K11为竖向节点线，K12为渐变细长箭头，K13为双向循环弧箭头。依据关系选择原生部件或连接线，保留可编辑性。一个对象能表达清楚的关系优先使用一个对象；完整的折线、转折和反馈路径用一条原生连接对象表达。渐变箭头按需使用，普通连接线同样属于可选方案。箭头方向必须与信息关系一致，转折或分支流程可保留原生连接线，不为统一外观牺牲清晰的连通关系。

参考页仅示意组合方式。按实际图文比例调整宽高、头部大小、间距和线宽，避免细箭头被拉成大块，或把图框、文字一起压缩。圆角按需减小，正文仍优先直角或小倒角。渐变沿用主蓝与浅蓝，文字保持足够对比。

组合范例由元素库统一维护。两种比例的母版文件仅保留封面、目录、三种正文版式、字体色板与自由版式；新增或更新组合时只更新元素库及其分类索引。
