# Academic PPT 元素与排版索引

当前为审阅稿，包含95种排版组合与13类独立部件，共108项参考。原有编号保持稳定，已按用户提供的原生元素更新箭头及相关版式。

入口：`assets/element-reference.pptx`。第1页为封面，第2—5页为可点击索引，第6—113页为独立参考，第114页为空白补充入口。

每次调用先执行 `scripts/inspect_reference_state.py`。用户登记副本或补充区有变化时，按 [补充模板与创新经验](library-workflow.md) 先整理再制作。

参考比例可按实际内容调整。复制主体组合或独立部件后，协调尺寸、文字密度与连接方向。正式汇报移除库编号、用途与导航。页面标题36磅、正文按24/22/20磅分层；图例及辅助标注可适当减小。

库内每页右上角为Arial 20磅“当前页/总页数”，与两种比例的母版一致。复制组合到汇报时，只保留汇报自身的一份页码，并在最终页序确定后重新校准，不沿用参考库的总页数。

用户确认的最终版优先。模板库的新增候选不直接写入Memory；Memory仅按具体创新页的明确反馈更新。
